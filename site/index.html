What it does

Financial research

Companies, filings, fundamentals and news, with every claim tied to the source that produced it.

Quantitative analysis

Deterministic engines compute the numbers — formula, inputs and assumptions attached.

Backtesting

Anti-lookahead backtests, walk-forward evaluation, Deflated Sharpe and overfitting checks.

Agent automation

Scheduled agents, workflows and durable runs, with permissions and tool effects declared.

Built as a harness, not a wrapper

Provider-agnostic model runtime, a local market-data vault, sandboxed Python, persistent memory and a controlled trading boundary. The model plans and explains; the engines compute. A number it cannot source reads UNAVAILABLE instead of being guessed.
