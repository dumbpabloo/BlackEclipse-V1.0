Black Eclipse

Black Eclipse is an open-source agentic harness designed to help you automate finance.

Agents that plan, call tools, run deterministic Python for the math, check their own sources, and keep a durable record of what they did — on your machine, with your own model.

Features

Six capabilities, one runtime. The model plans and explains; the engines compute.

Research with receipts

Companies, filings, fundamentals and news. Every claim carries the handle of the source that produced it; conflicts are disclosed, not averaged.

Deterministic finance engine

Metrics, ratios, valuation and risk run in Python with formula, inputs, assumptions and seed attached.

Strategy and backtesting

Versioned IR, visual graphs or sandboxed Python — tested with anti-lookahead backtests, walk-forward, Deflated Sharpe and an overfitting check.

Portfolio and journal

Holdings, performance, allocation, exposure, risk decomposition, a trading journal and broker reconciliation.

Agents, bots and automation

Cron, event and condition triggers; durable runs with leases and retries; agent teams, persistent memory and reviewed skills.

Trading, gated

MetaTrader 5 behind single-use approvals, demo mandates, margin caps and a kill switch — or a refusal naming the missing gate.

How it works

A harness, not a wrapper. The model plans and explains; deterministic engines compute; every effect is declared and recoverable.

1 · PlanThe agent chooses tools and states its intent
2 · ActTools run with declared permissions and effect classes
3 · ComputePython returns numbers with formula, inputs and seed
4 · VerifyClaims carry source handles; gaps return UNAVAILABLE
5 · RecordThe durable run keeps the plan, calls and receipts

Bots: scheduled agents that report what each source returned and mark the rest UNAVAILABLE instead of filling the gap.
